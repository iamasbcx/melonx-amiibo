# 塞尔达系列：按游戏分类的虚拟 amiibo 目录

将本目录整体放入 MeloNX 的 `Amiibo/`。每个 16 位 Title ID 文件夹只对应一款 Switch 游戏；应用只读取当前游戏文件夹里的 `amiibo.txt` 与 `custom.txt`。

| 游戏 | Title ID | 条目 |
| --- | --- | ---: |
| 塞尔达传说 旷野之息（荒野之息） | `01007EF00011E000` | 27 |
| 塞尔达传说 王国之泪 | `0100F2C0115B6000` | 32 |
| 塞尔达传说 织梦岛 | `01006BB00C6F0000` | 32 |
| 塞尔达传说 御天之剑 HD | `01002DA013484000` | 1 |
| 塞尔达传说 智慧的再现 | `01008CF01BAAC000` | 28 |
| 塞尔达无双 灾厄启示录 | `01002B00111A2000` | 28 |
| 塞尔达无双 海拉鲁全明星豪华版 | `0100AE00096EA000` | 22 |

`参考/all-amiibo.txt` 保存固定公开快照的全部 **932 个身份**，作为旁边备用，应用不会自动加载这个文件。它不代表 932 项均适用于上述游戏。

各游戏列表按 AmiiboAPI 的 `gamesSwitch` 明确关联生成，保留原始 16 位 ID；32 个塞尔达身份使用简体中文名称。
手机仍可按原有功能自行添加 `custom.txt`；此次文件包不覆盖它。返回应用或点“刷新目录”即可重新读取。

这份目录是用户主动导入的数据，不改变 IPA 默认空目录的设计。它仅含公开名称、身份 ID、用途文字与许可，没有 `.bin`、`.nfc`、密钥或标签应用区存档。
目前只核验公开关联、格式、去重、条目数和文件摘要，尚未逐项验证手机游戏效果。狼林克心数、织梦岛迷宫保存/分享等应用区效果不作保证。

《旷野之息》公开网站列出 29 个特定 amiibo，但其中两款 Young Link / Young Zelda（Ocarina of Time）标为未发售，固定数据库中也没有可核实 ID。本目录采用 27 个可核实身份；未使用猜造 ID。
未加入 3DS、Wii U、Switch 2 游戏目录；也未把仅有通用奖励、没有明确逐项关联的全目录混入各游戏列表。

# 游戏库自定义备注

在游戏卡片或列表项上长按，选择“修改备注”。输入内容后选择“保存备注”；选择“取消”不会改变原备注。保存空文本会删除备注，因此游戏名和公司名下方不再显示第三行。

备注只属于游戏库界面，不会写入 ROM、游戏元数据、每游戏配置或导出文件。数据存放在应用 `UserDefaults` 的 `GameLibraryRemarks` 字典中：有有效 Title ID 时使用规范化的 16 位十六进制 Title ID；没有 Title ID 时使用应用 Documents 下的相对文件路径，路径不在 Documents 时使用规范化 URL 作为明确 fallback。

备注最多保存 500 个字符。超出时保留完整草稿、显示超限提示并禁用保存，不自动截断中文输入或粘贴内容。编辑完成后通过共享可观察仓库立即刷新网格和列表；重启应用后从同一 UserDefaults 字典恢复。普通卡片和列表在游戏名、公司名下方显示单行备注，较长内容以省略号截断，重新进入“修改备注”可查看完整内容。紧凑图标和轮播布局仅提供修改入口，不额外显示文字。

Windows 已通过本地化资源检查和 `git diff --check`，并完成持久化逻辑的源码审查；没有 Apple SDK，未执行 Swift 编译或 iPhone UI 实测。待验收：分别在卡片/列表长按添加备注、取消草稿、修改并保存、清空后隐藏、超长中文与粘贴输入、重启后恢复，以及同 Title ID 文件共用备注。

# 屏幕手柄网格定点开发方案（当前实现状态）

## 1. 目标与范围

本方案针对 `MeloNXAmiibo` 的屏幕手柄编辑器，解决拖动控件难以精确定位的问题：

- 编辑时显示网格参考线；
- 调整网格间距，适配不同屏幕和布局密度；
- 按钮、摇杆拖动结束后自动吸附到网格点；
- 提供上、下、左、右微调按钮，便于在吸附后继续修正位置；
- 保留现有整体手柄透明度设置，不新增单按钮透明度字段或设置项。

正常运行游戏时不显示网格和编辑工具，不改变现有触摸输入链路。

## 2. 已完成的代码改动

### 2.1 本地锁定 `Melo-Controller`

网格功能位于 Swift Package 内，主工程已改为使用本地依赖：

- 包路径：`src/MeloNX/Dependencies/Melo-Controller`
- 工程配置：`src/MeloNX/MeloNX.xcodeproj/project.pbxproj`
- 依赖锁定：`src/MeloNX/MeloNX.xcodeproj/project.xcworkspace/xcshareddata/swiftpm/Package.resolved`

这样可以固定当前源码，避免远程 `branch = main` 变化导致功能漂移。

### 2.2 布局数据和网格规则

文件：`src/MeloNX/Dependencies/Melo-Controller/Sources/Melo-Controller/Models/Layout.swift`

`LayoutConfig` 新增：

- `gridEnabled: Bool`：编辑器网格和吸附开关，默认关闭；
- `gridSpacing: CGFloat`：网格间距，默认 `16`，限制在 `8...64`，步长为 `4`。

已有布局文件缺少新字段时使用上述默认值。吸附使用统一的四舍五入规则，正负坐标对称；开启网格或修改间距时，会将已有按钮和摇杆位置整理到当前网格。

### 2.3 编辑器显示和设置

文件：

- `ControllerView.swift`
- `Layout/LayoutEditorView.swift`

编辑状态显示不拦截触摸的网格参考线。全局编辑器选项中增加“网格吸附”和“网格间距”设置；运行状态不会绘制网格。

### 2.4 拖动吸附和方向微调

文件：

- `Buttons/ButtonView.swift`
- `Joystick/JoystickView.swift`
- `Layout/LayoutEditorView.swift`

按钮和摇杆拖动结束时，位置会按当前网格间距吸附。编辑器选中控件后显示四向微调面板：

- 网格开启时，每次移动一个网格间距；
- 网格关闭时，每次移动 `1 pt`；
- 操作始终作用于当前选中的按钮或摇杆；
- 位置继续使用现有安全区和布局坐标体系。

当前微调按钮实现为单击移动；长按连续移动尚未加入，后续如有需要再单独实现并测试。

已通过连接的 iPhone 导出配置进行检查：

- 设备：`iPhone19,2`，`iOS 27.0.1`；
- Bundle ID：`com.stossy11.MeloNX.947628J97T`；
- 导出目录：`_杂项/手机取证-20261109/Documents/Documents/`；
- `config.json` 与游戏配置中的 `controllerType1...controllerType8` 均为 `1`，即 `ProController`。

因此，配置文件没有被删除或损坏。虚拟手柄是否被选中主要保存在 `UserDefaults`，不在上述 `config.json` 中。旧安装包存在启动时控制器列表异步初始化、空选择未回退以及全局配置与游戏专属配置作用域不一致等问题，可能造成“界面显示手柄但按键无反应”或重启后显示“未选择控制器”。

已修复的源码链路包括：

- 启动时将虚拟手柄补入内部控制器列表；
- 空选择时回退到 `ProController`；
- 游戏运行期间新增、删除或修改控制器后立即重新 attach；
- 全局设置与游戏专属设置使用同一作用域读写；
- 运行时保存控制器类型时写入当前游戏配置；
- 控制器进入 `.started` 状态后再执行 attach。

这些修复必须重新编译并安装 IPA 后才能在手机上生效，当前 Windows 环境无法直接运行 Xcode 编译。

## 4. 透明度导致输入失效的排查与修复

真机测试反馈“修改手柄透明度后按钮失效”。原因是透明度原来作用于整个 `ControllerView`，而 UIKit 输入视图同时按 `alpha` 判断触摸目标；旧版 `UserDefaults` 中若存在 `0`、极小值或异常值，按钮可能仍可见但不会进入命中链路。

当前已修复：

- `EmulationView` 读取透明度时限制到 `0.05...1.0`，非有限值回退到 `1.0`；
- `SettingsView` 保存透明度时同样限制范围，避免再次写入无效值；
- `ControllerTouchRouter` 不再用视觉 `alpha` 过滤输入目标，透明度只影响显示，不决定是否可点击。

真机需要重新安装本次构建后验证 `1.0`、`0.5`、`0.05` 三档透明度，以及修改透明度后按钮、摇杆和滑动切换是否仍有输入。

## 5. 右摇杆与 XYAB 触屏布局

右侧区域已调整为上下分区：XYAB 在上方，右摇杆在下方。两者使用独立的触摸区域，避免原先重叠布局中 XYAB 覆盖右摇杆输入的问题。右摇杆仍通过现有 `joystickMoved(position:right:)` 链路发送输入，摇杆激活时保留原有的 XYAB 隐藏效果。

横屏和竖屏均采用同一排列规则；布局编辑器仍可通过网格和拖动调整位置。

6. 在设置中添加、删除和切换控制器，确认运行中立即生效；
7. 重启应用，确认控制器选择和游戏专属设置保持；
8. 进入布局编辑器，验证网格开关、`8...64 pt` 密度、拖动吸附和四向微调；
9. 检查横屏/竖屏、iPhone/iPad 安全区以及全局布局与游戏专属布局；
10. 采集运行日志，重点搜索 `AttachGamepad`、`gamepad not found`、`No matching controllers found`。

# 简体中文界面

应用新增 `zh-Hans` 字符串资源，系统或应用语言为简体中文时显示中文。菜单、设置分类、常用控件、标题、手柄映射文字和弹窗按钮在显示层查找本地化资源。

本次汉化保留原字符串键、配置编码、枚举原值、按钮回调标识、游戏 Title ID 和 C ABI。用户游戏名、文件路径、设备数据、原始报错和第三方许可证按原文显示。格式参数、Markdown 标记与模板变量由 `scripts/check_localization.py` 检查，并纳入 Codemagic 构建入口。

当前 468 个界面资源键均提供 `zh-Hans`，其中 360 项有中文译文；键帽、API 名称、比例、数字和第三方原文保留原样。系统蓝牙和本地网络权限说明另在 `Assets/zh-Hans.lproj/InfoPlist.strings` 提供中文。

Windows 已验证资源 JSON、格式参数和脚本语法；尚未运行 Xcode 中文界面编译，也未验证手机上的布局、截断或全部点击流程。这些结果应在首次云端构建与安装后补充，不能由资源检查推定为真机功能全部通过。
